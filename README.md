# 모루 — 한 단어씩 쑥쑥

한국어 사용자를 위한 일본어·영어 단어 학습 앱입니다. React + Vite로 만든 정적 사이트이며, 별도 서버·로그인·유료 API 없이 실행됩니다.

## 제공 기능

- 일본어 / 영어 전환, 필수·회화·자주 쓰는 단어·어려운 단어·전체 탭
- 히라가나 104장 / 가타카나 104장 문자 카드
- 누르면 뒤집히는 카드, 한국어 뜻, 기본 어휘의 예문·번역
- **한글 힌트는 처음에 숨김**. 힌트 버튼을 누르면 보이고 다음 카드에서는 다시 숨겨집니다.
- 선택한 분류의 **전체 카드 탐색**. `1 / 129`의 129는 현재 분류의 전체 카드 수입니다. 하루 목표 20개와는 별개입니다.
- 녹음 우선 발음 재생, 기기 음성 합성 대체, 0.75 / 1 / 1.25배 속도
- 기억 정도에 따른 복습 예약: 모르겠어요 10분, 애매해요 1일, 알아요 3일 이후(연속 성공 시 간격 증가)
- 즐겨찾기·오답노트, 단어/뜻/발음 검색, 목록 탐색
- 뜻 맞히기·듣기 10문제 퀴즈, 하루 목표·연속 학습·최근 14일 기록
- 브라우저 저장, JSON 백업·복원(기존 기록과 병합), 모바일 대응

## 실행

Node.js 22.12 이상을 권장합니다.

```sh
npm ci
npm run dev
```

```sh
npm test
npm run build
npm run preview
```

`dist/`가 배포 결과입니다. `index.html`을 파일로 직접 여는 대신 위 개발 서버나 정적 HTTP 서버를 사용하세요.

## GitHub Pages

저장소: https://github.com/angrieta/moru-vocabulary

`.github/workflows/pages.yml`이 `main`에 push할 때 테스트·빌드 후 GitHub Pages에 배포합니다. 저장소 Settings → Pages → Source가 **GitHub Actions**여야 합니다. Vite의 상대 경로 설정 덕분에 저장소 하위 경로에서도 동작합니다.

## 데이터 범위와 품질

| 데이터 | 개수 |
| --- | ---: |
| 일본어 단어·표현 | 7,922 |
| 히라가나·가타카나 문자 카드 | 208 |
| 영어 단어·표현 | 20,004 |
| 합계 | 28,134 |
| 예문·번역을 함께 편집한 시작 어휘 | 256 |
| 실제 공개 녹음 | 422 |

모든 단어가 독립적인 기본형은 아닙니다. 표기 변형·활용형·표현을 포함합니다. 필수 일본어 129개, 영어 127개와 회화 일본어 48개, 영어 46개는 별도로 분류되어 있습니다. 확장 단어는 공개사전 자료이며 대표 뜻·난이도·자동 한글 발음에 오류가 남아 있을 수 있습니다. 순위·등급은 학습용 추천이며 공인 시험 등급이나 정확한 회화 빈도 통계가 아닙니다.

일본어 전체와 영어 16,445개에 한글 보조가 있습니다. 일부 영어에는 IPA/한글 힌트가 없습니다. 실제 녹음이 없는 항목은 **합성 음성**으로 표시합니다. 기기에 해당 언어의 음성이 설치되어 있어야 합성 음성이 동작하며 외부 녹음과 글꼴은 인터넷 연결이 필요합니다. 녹음 서버의 요청 제한이나 연결 실패 시 합성 음성으로 전환합니다.

자세한 출처·저작자·변경 내용·라이선스는 [DATA-NOTES.md](DATA-NOTES.md), [AUDIO-NOTES.md](AUDIO-NOTES.md), `public/licenses/`, `public/audio-credits.html`에 있습니다. 화면의 사용 가이드에서도 접근할 수 있습니다.

## 저장과 개인정보

학습 기록은 `localStorage`의 `moru-learning-v1`에 저장합니다. 서버에 학습 기록을 전송하지 않습니다. 브라우저나 도메인이 바뀌면 별도 기록으로 취급되므로 설정에서 JSON을 내보내고 새 사이트에서 가져오세요. 예를 들어 로컬 미리보기의 기록은 GitHub Pages로 자동 이동하지 않습니다. 같은 날 같은 단어는 하루 목표에서 한 번만 셉니다.

## 프로젝트 구성

- `src/main.jsx` — 학습 화면, 단어장, 퀴즈, 설정
- `src/model.js` — 복습 일정·검색·백업 병합
- `src/audio.js` — 녹음·기기 음성 및 재생 취소
- `src/Buddy.jsx` — 이 프로젝트의 새싹 캐릭터
- `src/style.css`, `src/playful.css` — 반응형 구조와 귀여운 디자인
- `public/data/` — 단어 및 음성 메타데이터
- `scripts/build-data.mjs` — 고정 스냅샷에서 데이터 재생성
- `scripts/core-vocabulary.mjs`, `scripts/vocabulary-corrections.mjs` — 시작 어휘·대표 뜻 보정
- `tests/model.test.mjs` — 복습·저장·퀴즈·데이터 정합성 테스트
