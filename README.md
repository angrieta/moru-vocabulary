# 모루 — 한 단어씩 쑥쑥

한국어 사용자를 위한 일본어·영어 단어 학습 앱입니다. React + Vite로 만든 정적 사이트이며, 별도 서버·로그인·유료 API 없이 실행됩니다.

## 제공 기능

- 일본어 / 영어 전환, 필수·회화·자주 쓰는 단어·어려운 단어·전체 탭
- 히라가나 104장 / 가타카나 104장 문자 카드
- 누르면 뒤집히는 카드, 한국어 뜻, 기본 어휘의 예문·번역
- **한글 힌트는 처음에 숨김**. 힌트 버튼을 누르면 보이고 다음 카드에서는 다시 숨겨집니다.
- 선택한 분류의 **전체 카드 탐색**. `1 / 129`의 129는 현재 분류의 전체 카드 수입니다. 하루 목표 20개와는 별개입니다.
- **오늘의 학습**: 복습할 단어·헷갈린 단어·새 단어 순으로, 뜻 → 단어 → 듣기 → 예문 빈칸 퀴즈와 선택형 따라 말하기
- 먼저 답을 떠올린 뒤 4지선다 보기를 열거나, 단어·빈칸 정답을 직접 입력하면 자동 채점합니다. 일본어는 한자 표기와 가나 읽기를 모두 허용합니다.
- 틀리거나 힌트를 쓴 문제는 코스 끝에 한 번만 다시 나옵니다. 처음에 힌트 없이 맞힌 점수와 재도전 결과를 따로 표시하며, 재도전으로 하루 학습 단어 수가 중복 집계되지 않습니다.
- 하루 새 단어 5 / 10 / 15개 설정(두 언어 합산), 같은 날 코스 이어하기
- 검증된 사람 녹음 우선, 나머지는 미리 생성한 **AI 합성 MP3**. 브라우저 음성 설치 없이 재생하며 종류를 구분합니다.
- 기억 정도에 따른 복습 예약: 모르겠어요 10분, 애매해요 1일, 첫 알아요 3일. 틀렸다가 다시 떠올리면 1일 뒤, 24시간 안에 반복 성공해도 간격이 계속 늘어나지 않습니다.
- 역방향 입력·4지선다 자동 채점, 듣기 속도·글자 힌트, 256개 예문·빈칸·음성 따라 말하기
- 힌트 사용은 더 이른 복습에 반영하며, 음성 재생 실패는 오답이나 학습 완료로 기록하지 않습니다.
- 즐겨찾기·오답노트, 단어/뜻/발음 검색, 목록 탐색
- 뜻 맞히기·듣기 최대 10문제 퀴즈, 하루 목표·연속 학습·최근 14일 기록
- 만나본 단어 / 힌트 없이 연습 성공 / 24시간 뒤에도 기억한 단어를 구분한 성장 기록
- 브라우저 저장, JSON 백업·복원(기존 기록과 병합), 모바일 대응

## 실행

Node.js 22.12 이상을 권장합니다.

```sh
npm ci
npm run dev
```

```sh
npm test
npm run build
npm run preview
```

`dist/`가 배포 결과입니다. `index.html`을 파일로 직접 여는 대신 위 개발 서버나 정적 HTTP 서버를 사용하세요.

## GitHub Pages

저장소: https://github.com/angrieta/moru-vocabulary

`.github/workflows/pages.yml`이 `main`에 push할 때 테스트·빌드 후 GitHub Pages에 배포합니다. 저장소 Settings → Pages → Source가 **GitHub Actions**여야 합니다. Vite의 상대 경로 설정 덕분에 저장소 하위 경로에서도 동작합니다.

카카오톡 등 링크 공유 미리보기는 `index.html`의 Open Graph 태그와 `public/social/moru-share-v1.png`를 사용합니다. 공유 이미지는 내장 이미지 생성 도구로 제작했으며 프롬프트는 `design/moru-share-prompt.txt`에 있습니다. 도메인이나 저장소 이름을 바꾸면 canonical·Open Graph·Twitter 태그의 절대 주소도 함께 바꾸세요.

| 영어 단어·표현 | 20,004 |

모든 단어가 독립적인 기본형은 아닙니다. 표기 변형·활용형·표현을 포함합니다. 필수 일본어 129개, 영어 127개와 회화 일본어 48개, 영어 46개는 별도로 분류되어 있습니다. 확장 단어는 공개사전 자료이며 대표 뜻·난이도·자동 한글 발음에 오류가 남아 있을 수 있습니다. 순위·등급은 학습용 추천이며 공인 시험 등급이나 정확한 회화 빈도 통계가 아닙니다.

일본어 전체와 영어 16,445개에 한글 보조가 있습니다. 일부 영어에는 IPA/한글 힌트가 없습니다. 발음은 로컬 사람 녹음 → 로컬 AI 합성 파일 순으로 선택합니다. 듣기 퀴즈에는 사이트에 파일이 있는 단어만 출제하고, 실제 재생 시작을 확인한 후 답을 고를 수 있습니다. 파일이 없는 일반 카드에서만 외부 녹음·기기 음성을 마지막 대안으로 사용합니다. 파일과 글꼴을 처음 불러올 때 인터넷 연결이 필요합니다.

AI 합성은 일본어·기초 영어·예문에 Kokoro, 영어 확장 어휘에 Piper를 사용합니다. 발음·강세·억양을 모두 사람이 청취해 검증한 것은 아닙니다. 완성 범위와 파일별 해시는 `public/data/synthetic-audio.json`에 있으며, 웹앱은 언어별 경량 재생 목록만 읽습니다.

자세한 출처·저작자·변경 내용·라이선스는 [DATA-NOTES.md](DATA-NOTES.md), [AUDIO-NOTES.md](AUDIO-NOTES.md), [SYNTHETIC-AUDIO-NOTES.md](SYNTHETIC-AUDIO-NOTES.md), `public/licenses/`, `public/audio-credits.html`에 있습니다. 화면의 사용 가이드에서도 접근할 수 있습니다.

## 저장과 개인정보

일본어의 **한자 쓰기**에는 기초 한자 117자와 필수 단어의 한자를 합친 162자가 있습니다. 획순 재생 → 따라 쓰기 → 가이드 없이 쓰기 → 정답 겹쳐 보기로 연습합니다. 마우스·터치·펜과 종이 연습을 지원하며 자동 채점은 하지 않습니다. 자가 확인한 연습 횟수와 다시 쓸 한자는 기존 JSON 백업에 함께 저장하고, 필기 궤적은 저장하거나 전송하지 않습니다. 단어 퀴즈 점수와 복습 일정에는 영향을 주지 않습니다. 획순은 [KanjiVG](https://kanjivg.tagaini.net/), CC BY-SA 3.0 자료이며 [가공 내역](public/licenses/KANJI-NOTES.md)을 포함합니다.

학습 기록은 `localStorage`의 `moru-learning-v1`에 저장합니다. 서버에 학습 기록을 전송하지 않습니다. 브라우저나 도메인이 바뀌면 별도 기록으로 취급되므로 설정에서 JSON을 내보내고 새 사이트에서 가져오세요. 예를 들어 로컬 미리보기의 기록은 GitHub Pages로 자동 이동하지 않습니다. 같은 날 같은 단어는 하루 목표에서 한 번만 셉니다.

진행 중인 코스는 `moru-course-v1-ja/en`에 따로 저장해 당일 이어서 공부할 수 있습니다. 코스 저장 형식은 v2이며 기존 v1 코스도 남은 문제를 퀴즈로 전환해 이어갑니다. 이전의 자기 평가는 새 퀴즈 점수에 포함하지 않습니다. 답변은 ‘다음 문제’를 누를 때 학습 기록에 반영됩니다.

백업은 완료한 학습·연습 기록을 포함하며, 진행 중인 코스의 화면 위치는 포함하지 않습니다. 따라 말하기는 스스로 확인하는 선택 연습으로 퀴즈 점수에 포함하지 않으며, 마이크를 녹음하거나 자동 발음 점수를 매기지 않습니다.

## 프로젝트 구성

- `src/main.jsx` — React 진입점
- `src/App.jsx` — 학습 화면, 단어장, 설정과 데이터 로딩
- `src/Today.jsx`, `src/PracticeQuestion.jsx`, `src/learning.js` — 자동 채점 코스·직접 입력·선택지·오답 재도전·이어하기·성장 기록
- `src/Quiz.jsx` — 파일 기반 듣기, 힌트와 재생 실패 처리
- `src/Kanji.jsx`, `src/writing.js`, `src/kanji.css` — 획순 재생·필기 연습·자가 확인 기록
- `scripts/build-kanji.mjs` — 고정 KanjiVG 리비전에서 획순 자료 생성
- `src/model.js` — 복습 일정·검색·백업 병합
- `src/audio.js` — 사람·AI 음성 파일, 기기 음성 대안, 재생 확인·취소
- `src/Buddy.jsx` — 이 프로젝트의 새싹 캐릭터
- `src/style.css`, `src/playful.css`, `src/today.css`, `src/desktop.css` — 반응형 구조와 귀여운 디자인, 넓은 PC 학습 화면
- `public/data/` — 단어 및 음성 메타데이터
- `scripts/build-data.mjs` — 고정 스냅샷에서 데이터 재생성
- `scripts/bundle-audio.mjs`, `scripts/build-synthetic-audio.py` — 녹음 번들·합성 생성과 검사
- `scripts/build-audio-index.mjs` — 빌드 시 언어별 경량 재생 목록 생성
- `scripts/core-vocabulary.mjs`, `scripts/vocabulary-corrections.mjs` — 시작 어휘·대표 뜻 보정
- `tests/` — 복습·저장·이어하기·퀴즈·실패 시 재생·파일 해시 테스트
